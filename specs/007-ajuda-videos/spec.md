# Feature 007: Ajuda com videos

## Objetivo

Criar acesso em Ajustes para uma tela de Ajuda premium com videos do YouTube reproduzidos dentro do app e botao flutuante para atendimento via WhatsApp.

## Requisitos

- Ajustes deve exibir uma entrada "Ajuda" na secao "Suporte".
- A tela de Ajuda deve listar videos configuraveis.
- O video selecionado deve tocar dentro do app, sem abrir o YouTube.
- A tela deve ter visual premium e responsivo.
- A tela deve ter FAB para WhatsApp.
- O WhatsApp deve usar o numero da empresa salvo no painel/Supabase.
- Enquanto nao houver catalogo remoto, o app deve ter um video de teste: `HxgGW_ECu0w`.

## Fora de escopo

- Cadastro de videos pelo app mobile.
- Upload/hospedagem propria de videos.
