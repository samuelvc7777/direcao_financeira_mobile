# Speckit Specify Skill

Siga integralmente o arquivo `.specify/templates/commands/specify.md`.

Ao escrever a especificacao:

- use portugues;
- foque no que o usuario precisa e no valor da feature;
- evite detalhes de implementacao no `spec.md`, salvo quando o template exigir contexto tecnico fora da especificacao em si.
